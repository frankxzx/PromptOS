# Prompt Studio v1

A React + Vite prototype for a Prompt Studio admin portal focused on:

- Template library and builder
- Scenario library and scenario creation
- Reusable snippet library and snippet detail
- Visual / structured / raw template modes
- Role-based controls for `Editor` and `Admin`
- Version history, restore flows, and preview validation
- GitHub Pages deployment on push to `main`

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run build
```

## Deploy

GitHub Pages is deployed by GitHub Actions from the `main` branch.
